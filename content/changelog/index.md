This page is going to serve as a place where I can keep track of how I’ve built this website and developed it over time. I’ll add to it every time I make a considerable change or addition…

## 2025-01-30

Just a few small changes in the last couple of days. Created a new signup form for the [subscription](https://fundamentalised.com/subscribe/) page and added it to the main menu. I posted the first email for the new site just yesterday and it had good opens and clicks and other engagement (not sure if this is to do with the new site or the fact that I’ve gone back to using ConvertKit).

## 2025-01-28 (Genesis)

I’ve been building this site for the last four days or so, getting it up to speed with the entirety of Fundamentalised content (most of today has been spent copying issues and essays across).

I’ve built this site using Hugo, with Netlify to deploy. I’ve made use of the [PaperMod theme](https://github.com/adityatelange/hugo-PaperMod), and I write and commit the content to production from within [Obsidian](https://obsidian.md) (although most work has been done in Cursor up until now because I don’t know how to code).

I’ve added an [`/about`](https://fundamentalised.com/about/) page talking about who I am and what Fundamentalised is so that people can learn a little more. The content is divided into two categories at the moment, in the same way that it was on other platforms, with [Newsletter issues](https://fundamentalised.com/issues/) and [Short essays](https://fundamentalised.com/essays/) being the two directions that the reader can head in.

I’ve got some more plans for what I want to do with this site, but for now this is a perfect place to start from. I’m very happy with how this has turned out.
